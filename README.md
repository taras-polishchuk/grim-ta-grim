# grim-ta-grim

## Що це

Лендинг для українського рок-гурту **«Грим та Грім»** (концерти, квитки, брендинг).

Статична HTML-сторінка (без збирача, без залежностей).

## Як переглянути

1. Відкрити `index.html` напряму у браузері, **або**
2. Запустити локальний сервер:
   ```bash
   python3 -m http.server 8000
   ```
   і відвідати `http://localhost:8000/`

## Структура

- `index.html` — основна сторінка
- `style.css` — стилі
- `script.js` — інтерактив
- `favicon.svg` — іконка
